# CSET456 DevOps Lab 2

## Repository Mining and Dataset Preparation

This directory contains the implementation, datasets, statistics, analysis, screenshots, and documentation for CSET456 DevOps Lab 2.

## Objective

The objective of this lab is to mine software repositories, clean the extracted information, prepare separate source-code and commit-history datasets, and create a meaningful combined dataset.

## Repositories Used

The following five GitHub repositories will be mined:

1. Flask
2. Requests
3. Pytest
4. FastAPI
5. Scikit-learn

## Lab 2 Workflow

1. Repository mining
2. Source-code dataset generation
3. Commit-history dataset generation
4. Data cleaning
5. Combined dataset generation
6. Statistical analysis
7. Dataset analysis and use cases
8. Documentation
